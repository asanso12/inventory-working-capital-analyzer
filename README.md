# Inventory & Working Capital Analyzer

## Overview
This project analyzes how much inventory a company should hold, when it
should reorder, and how much cash that inventory ties up. It combines
supply chain concepts (demand variability, lead time, safety stock) with
finance concepts (carrying cost, ordering cost, working capital).

## Business Question
For a set of products, what inventory policy minimizes total cost while
meeting a target service level, and how does it compare to a simple
"order when we run out" approach?

## Tools Used
- **SQL (SQLite):** store and query sales, product, and supplier data
- **Python (pandas, matplotlib):** forecast demand and calculate EOQ,
  safety stock, and reorder points
- **Excel:** summary dashboard with adjustable assumptions
- **Git/GitHub:** version control and project documentation

## Project Structure
- `data/`   sample datasets (synthetic)
- `sql/`    database queries
- `src/`    Python scripts
- `output/` Excel workbook and charts
